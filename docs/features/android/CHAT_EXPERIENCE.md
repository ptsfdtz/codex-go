# 安卓对话体验

配对后直接进入对话。产品完整范围和当前验收状态以 [迁移状态](../../migration/CODEX_PARITY_STATUS.md) 为准；本页说明已有界面的使用方式。

## 导航与输入

1. Windows 授权项目、显示二维码，Android 扫码并在两端核对配对码，由 Windows 确认。顶部或设置可切换已配对电脑。
2. 侧栏按项目访问会话，支持搜索、筛选与排序；窄屏使用抽屉。新对话从已授权项目开始，归档入口在设置中的会话管理。
3. 输入框支持文字、附件、技能和项目文件引用，以及模型/思考强度、执行模式与权限选择。展开编辑器复用同一份草稿和操作；资源选择不会自动发送。
4. 当前电脑的未发送草稿可集中查找并回原会话继续编辑；前进/后退与会话阅读位置保留在应用内存。电脑/会话之间隔离，不承诺进程终止后的恢复。
5. 运行中可按实际能力追加文字、排队或停止。队列修改、历史修订、目标操作等保留原确认与服务端检查；操作受理不等于任务完成，结果未知时先刷新核对。

## 消息、资源与审批

- 对话合并原生持久历史与实时事件，按原 turn/item 身份去重；旧页和独立历史检查器保留来源边界。
- 消息支持 Markdown、代码块、引用、计划、代理和工具详情。长正文、原始记录与工具字段可分段查找/复制；完整“已加载”内容不代表源截断已恢复。
- 图片和文件通过既有授权与资源接口打开；缺失、未保存或项目外资源明确报错，不因消息中的路径自动获得文件权限。
- 审批和原生问题在会话内处理，显示确认、期限与状态；敏感回答只在内存处理。离线、过期或已处理请求不能再次提交，不新增自动批准策略。
- 文件图标进入 working-tree 只读审查。宽屏可并排，手机切换全宽面板；文件编辑、Git 写入和完整工作台仍待完成。

## 数据与验证

草稿在服务端确认受理后才按版本清理；代码与命令在界面只作内容展示。状态依据上游权威终态，不能用发送成功、工具退出或保存历史推断任务完成。API 模式的数据和凭据独立，见 [API 配置](CONVERSATIONS_AND_API.md)。

本页不是桌面逐页复刻或真机验收证据。旧布局、测试命令和设备记录保存在 [2026-10-20 历史快照](../../history/CHAT_EXPERIENCE-2026-10-20.md)，不自动继承为当前版本通过；当前实际验证见 STATUS。
