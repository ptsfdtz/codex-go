# 会话与独立 API

## Codex 编程模式

电脑本机授权项目，安卓连接后按项目访问会话。导航、输入框、历史、队列、目标与设置持续实现中；当前实现和未验收项统一维护在 [迁移状态](../../migration/CODEX_PARITY_STATUS.md)，不在本页重复能力矩阵。使用流程见 [对话体验](CHAT_EXPERIENCE.md)，接口见 [协议](../../design/PROTOCOL.md)。

会话管理与执行保留原生线程身份和权限检查；归档可恢复，删除需确认且不删除工作区文件。模型/强度取自真实账户目录，未知结果不自动重发。完整原版桌面共享尚未验收，不能把已索引线程等同于全部桌面内容。

## 平板独立 API 模式

无需配对：点顶部 **chat → 配置 API**，填写：

1. **HTTPS 基础地址**，例如 `https://api.openai.com/v1`。不要填完整 `/chat/completions` 路径，不能包含 URL 账号密码、查询串或片段。
2. 该服务商签发的 API 密钥。已有密钥不会回填到输入框；同地址留空可保留，更换地址必须重新输入，避免把旧密钥发给另一主机。
3. 模型 ID 可以留空。点击 **保存并获取模型** 时自动读取对端 `/models`，去重后加入模型菜单并加密保存；未填写模型 ID 时自动选择列表中的第一个。已有选择会保留。不提供此接口的服务商可以手动填写模型 ID，获取失败仍可保存手动配置。模型菜单中的 **获取并添加对端模型** 可刷新列表。

保存后即可发送，重启应用后保留模型列表和选择。使用 OpenAI 兼容 **Chat Completions**：`POST {base}/chat/completions`、Bearer 认证、文本历史、SSE 流式回复；也接受有明确终态的普通 JSON 回复。默认不发送思考强度，显式选择时使用 `reasoning_effort`。模型列表接口不声明这一参数的能力，因此 API 模式的思考强度能否使用取决于服务商和模型，不支持时保留失败状态，不静默改参数。

两种模式的数据隔离：API 消息直接从平板发给所配置服务商，不经过 Windows，也不使用 Codex 登录信息。它是文本对话，不具有项目文件、工具执行、Codex 审批或 Git 能力。连接仍执行正常 TLS 验证，禁止明文 HTTP 和重定向，没有“忽略证书”选项。

chat 会话支持新建、继续、停止、搜索、置顶、重命名、归档/恢复、删除及复制。删除仅移除平板记录，不承诺删除服务商留存。回复只有收到明确 `stop` 完成原因（流式还需 `[DONE]`）才标为完成；提前断流、长度限制、内容过滤、工具调用或不兼容格式显示失败，并保留已收到的部分。用户停止显示中断；应用意外重启时此前运行中的回复变为未知。

API 密钥和会话整体用 Keystore AES-GCM 加密，原子写入应用私有文件；系统备份关闭。仅支持一个 API 配置。最多 100 个会话、每会话约 500 条消息、单次输入 64,000 字符、回复显示 512 Ki 字符、加密前文档 3 MiB。达到上限需删除旧记录。部分流式文本直到结束/停止后才保存，进程意外结束可能失去尚未保存的片段。

## 验证边界

API 与 Codex 模式分别验证，不共享凭据或业务数据库。目录、配置和界面已实现不等于实际服务商/设备通过；最新代码检查见 [当前状态](../../migration/CODEX_PARITY_STATUS.md)，既有测试证据见 [历史验收记录](../../history/ACCEPTANCE.md)。密钥在平板配置，不粘贴到聊天或日志。
