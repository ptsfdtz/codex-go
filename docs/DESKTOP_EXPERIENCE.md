# Windows 桌面体验

当前版本使用 Tauri 2 + React + Rust，沿用 Android 的黑白灰配色、普通字号、轻量圆角和跟随系统的深浅主题。首页是一列简洁的连接设置：工作区数量与同步按钮、平板名称与连接状态。移除宣传大标题、英文标语、插画、项目预览列表和左右分栏。

未配对时点击“显示配对码”，已连接时直接显示设备状态，无需重复扫码。工作区数量可点击查看、搜索和管理完整目录；连接详情收在底部文字入口。780×600 最小窗口下，配对流程无需整页滚动。二维码始终使用白底以保持可扫描性。

更多菜单承载工作区搜索/本机目录授权、设备撤销、待审批和连接详情。配对码 120 秒有效，核对六位码后手动确认；审批显示完整内容并二次确认。窗口 × 收起到托盘，托盘或更多菜单可停止并退出。

实现目录为 `desktop/`：React 界面、Tauri Rust 宿主和 `core/` 原生 Rust Bridge。旧 Node/WinForms 实现已删除。构建方法与验证边界详见 [Tauri 迁移说明](TAURI_MIGRATION.md)。
