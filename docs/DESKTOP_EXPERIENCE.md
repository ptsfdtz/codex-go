# Windows 极简连接窗口

首页只做两件事：**同步 Codex 工作区 → 平板扫码配对**。无系统标题栏、无侧栏、无默认管理列表。窗口顶部可拖动，边缘可调整大小；右上角为更多、最小化、收起到托盘。停止程序在更多或托盘菜单中。

## 使用

1. 点击 **同步 Codex 工作区**。把可发现的本机项目目录授权给 AgentDeck，并自动选择局域网地址生成二维码，无需逐个选择文件夹或地址。
2. 平板扫码，两屏核对六位码，在电脑确认。已有配对保留，可直接继续使用，无需为升级重配。

同步后显示项目总数和同步时间。邀请 120 秒有效，过期后可重新显示配对码。已同步且保存了本机 LAN 授权的窗口下次启动会显示新二维码；首次启动不自动授权目录或开放 LAN。

项目明细、补充文件夹、撤销设备、审批、网络地址和证书指纹收在 **···** 中。审批仍保留完整操作检查，确认框默认键盘操作为取消；不会自动批准。操作已处理不等于 Codex 任务已完成。

## 同步范围

CLI 0.159.2 稳定协议没有“桌面侧栏全部项目”的列表接口。实现使用官方 `config/read` 的已信任项目配置，以及 `thread/list` 全分页返回的会话 cwd，覆盖 cli/vscode/appServer、所有模型提供商、归档与未归档会话。不读取桌面私有状态、登录文件或终端输出。

路径取 realpath 并去重，只导入存在的本机目录；跳过缺失路径、临时目录、Codex 数据目录、用户主目录本身和盘符根。反复同步保留原 projectId；同步只增加/重新授权，不删除其他项目或文件。发现本身不授权；授权只发生在 Windows 本机同步动作，远程协议没有同步接口。

结果可能包含历史会话仍存在的目录；只在桌面添加、从未进入配置或会话记录的目录可能不可发现，可从更多菜单补充。目录同步不导入或接管桌面正在运行的聊天。过多记录、重复分页或非法响应会明确失败，不伪称全部同步。最多 1,000 个候选目录，单个归档分组最多 100 页。

本机运维可显式运行 `node bridge/dist/bridge/src/main.js --sync-workspaces`，等价于本机同步按钮并生成邀请；普通启动不执行新的目录同步。

## 本轮验证

- 构建、TypeScript/ESLint、格式检查；**36 个 Vitest 测试**，新增分页、归档、去重、重复同步 ID、安全跳过、非法响应与重复 cursor 测试。
- `pnpm verify:windows` 实际编译运行窗口，检查无系统标题栏/无侧栏、700×560 / 780×620 / 1120×740 三尺寸和四种页面共 12 组布局；保留真实 DPAPI、证书、长审批上下文、过期禁用、二维码有效期和选择保持测试。
- `pnpm exec tsx scripts/smoke-workspaces.ts` 使用真实 Codex，只读发现并在内存注册表同步 18 个项目，跳过 62 个无效或临时目录，重复同步 ID 不变。不写生产授权或执行 Codex 任务。
- 编译后的生产入口使用原配对数据显式同步成功：18 个项目加原有 2 个测试授权，共 20 个项目，保存同步时间；实际窗口显示真实二维码和原平板在线。未代替用户重新配对或审批。

证据：`artifacts/workspace-sync-smoke.json`、`windows-native.json`、`desktop-simple-verification.json`、`bridge-tests.xml`。原 APK 不变；发布补测边界仍见 ACCEPTANCE.md。
