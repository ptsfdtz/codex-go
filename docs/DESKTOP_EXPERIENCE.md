# Windows 桌面体验

当前版本使用 Tauri 2 + React + Rust，采用暖白底色、深绿主操作、自绘标题区。首页只有工作区同步和扫码连接两个区域。已配对设备优先显示当前连接状态，离线时等待重连，不强迫重新扫码。

更多菜单承载工作区搜索/本机目录授权、设备撤销、待审批和连接详情。配对码 120 秒有效，核对六位码后手动确认；审批显示完整内容并二次确认。窗口 × 收起到托盘，托盘或更多菜单可停止并退出。

实现目录为 `desktop/`：React 界面、Tauri Rust 宿主和 `core/` 原生 Rust Bridge。旧 Node/WinForms 实现已删除。构建方法与验证边界详见 [Tauri 迁移说明](TAURI_MIGRATION.md)。
