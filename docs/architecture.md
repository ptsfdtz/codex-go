# 架构与安全边界

[开发入口](../AGENTS.md) · [开发验证](development.md)

## 组件与状态归属

| 组件              | 职责与权威状态                                                         |
| ----------------- | ---------------------------------------------------------------------- |
| Web/PWA           | 跨平台操作入口，展示会话、文件、审批及恢复状态；草稿和偏好按浏览器隔离 |
| 电脑 Host / Codex | 执行任务，保存 Codex 会话权威状态、项目授权、附件和审批恢复信息        |
| 云端              | 保存账户凭据、设备归属与撤销状态，提供认证和加密连接转发               |
| 自有 VPS          | 承载云端连接入口，不执行模型任务，不保存 Codex 聊天或媒体              |
| AgentChat         | 浏览器直连兼容供应商，聊天记录本地保存；云端仅保存加密 API Key         |

Host、CLI 和原版桌面共享同一认证原生运行时是目标，具体已验证平台及候选限制见[运行时验收](runtime.md)。普通独立启动的 `codex` 不会自动加入共享运行时。

## 项目、附件与同步

项目名称及顺序只取自原生 `project/list`；会话跟随原生目录。完整同步隐藏失效索引，不删除历史或撤销授权；归档会话可跨项目读取，已删除会话不显示。项目自动登记使用官方 `project/create`，主动移除的项目不自动恢复。

附件统一存于 Host 附件库，按 SHA-256 去重并保留会话授权引用；历史附件沿用原路径。图片按授权分块读取并核对哈希和资源变化，外部 HTTP(S) 图片不自动请求。不得开放整个状态目录。

桌面外部变化同步：managed 模式监听 Codex 初始化接口返回目录的系统文件通知，仅把路径当作失效提示，不读取私有数据库或解析会话文件；通过官方接口重新核对会话身份、项目授权和索引，再发送可重放的 `session.contentChanged`。Web 合并短时重复通知，只补读当前可见会话最近一页，保留更早历史、草稿、工具展开和阅读位置；并发流式内容优先，页面返回前台后补读。附着模式继续使用原生通知，原有 15 秒索引核对周期不变，时间戳前进时也提示补读，以恢复遗漏通知。

## AgentChat

对话、接口配置及草稿保存在当前账户的浏览器 IndexedDB，不跨设备同步；云端 `chat_keys` 保存账户归属和加密密钥，不保存聊天。浏览器直接请求供应商 `/models` 与 `/chat/completions`，不携带本站 Cookie、CSRF 或 Referer，不跟随重定向；供应商须允许 CORS。清除浏览器数据会丢失本地历史，关闭页面不能继续生成。

每页最多同时生成 2 条，单条输入上限 12,000 字节、输出 512 KiB、生成 5 分钟。停止会关闭直连请求，断流或刷新不自动重发，未知发送结果须明确确认。当前为纯文字兼容接口，不支持附件、工具或原生 Claude/Gemini 协议。参考 NextChat 的来源与 MIT 许可证保留在 `third_party/nextchat/`。

## 工作区工具栏与 SSH（源码新增）

Web 的主对话与侧边对话共用认证后的 Host 连接和快照，分别保存所选会话、历史、流式条目及输入草稿。历史读取共用有界分块及哈希校验；任务、审批和追问继续通过原有固定协议，保留原生身份和未知结果核对。

SSH 是用户手动操作的终端：Host 以自身系统用户启动固定的 OpenSSH 客户端并分配 PTY，Web 用 xterm 显示。新增 `sshTerminal` 能力和 `ssh.open/read/write/resize/close` 固定操作，主机、用户、端口、私钥路径和终端尺寸独立校验，不接收客户端命令行、程序路径或任意 RPC。使用 Host 已有 SSH 配置、密钥和 known_hosts；禁用 SSH 本地转义命令、LocalCommand、转发和连接复用，保留交互式指纹校验。SSH 账户权限与 Codex 项目沙箱分别处理，终端不改变 Codex 的项目授权和执行审批。

终端按已认证 WebSocket 连接和设备归属隔离，最多每连接 2 个、Host 合计 4 个；输出仅在 Host 内存中有界保存 512 KiB，以字节游标分块读取，落后游标明确报告截断。输入按序号确认并在内存中防止重复接收，不进入通用持久操作回执；输入、密码及输出不写入聊天、事件库或诊断。关闭网页连接会关闭对应 PTY，包括尚未完成创建的请求；设备撤销和 Host 停止同样清理，终端不会在恢复时自动重连或重放输入。活跃终端参与 Host 空闲更新检查。云端仍只转发加密连接，无新增数据库迁移；旧客户端忽略新增能力，旧 Host 不提供终端入口。

## 必须保留的边界

- 服务端附着的 Codex 是权威源，保留原 `thread/turn/item` 身份；发送 ACK 不代表完成，结果未知先核对，不自动重发。
- 不复制或写入 Codex 私有数据库，不暴露任意 RPC，不因远程访问放宽项目授权或执行确认；凭据不进入文档、日志或测试产物。
- Web 使用 Origin 白名单、HttpOnly Cookie、CSRF 和一次性隧道票据；内层 TLS 校验电脑证书。证书错误不自动回退；浏览器阻止 LAN 时走公网。当前账号 LAN 也依赖云端复核，不承诺云端离线可用。
- 不随意修改协议序列化身份或 Rust 公开入口；旧配对协议仅兼容旧记录和客户端。
- 上游 schema 是生成物，升级 Codex 时显式重导出和核验，不手改；仓库保留独立消息定义，导出与审计统一排除重复聚合包，保留逐文件哈希校验。设置等 Rust 兼容接口保留。
- 附着成功不等于日常原版桌面已经切换；桌面当前运行状态与未完成验收见[运行时验收](runtime.md)与[功能状态](status.md)。
- 不自动修改防火墙，不绕过设备安装确认。
