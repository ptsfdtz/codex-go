# 架构与安全边界

[开发入口](../AGENTS.md) · [开发验证](development.md)

## 组件与状态归属

| 组件              | 职责与权威状态                                                         |
| ----------------- | ---------------------------------------------------------------------- |
| Web/PWA           | 跨平台操作入口，展示会话、文件、审批及恢复状态；草稿和偏好按浏览器隔离 |
| 电脑 Host / Codex | 执行任务，保存 Codex 会话权威状态、项目授权、附件和审批恢复信息        |
| 云端              | 保存账户凭据、设备归属与撤销状态，提供认证和加密连接转发               |
| 自有 VPS          | 承载云端连接入口，不执行模型任务，不保存 Codex 聊天或媒体              |
| AgentChat         | 浏览器直连兼容供应商，聊天记录本地保存；云端仅保存加密 API Key         |

Host、CLI 和原版桌面共享同一认证原生运行时是目标，具体已验证平台及候选限制见[运行时验收](runtime.md)。普通独立启动的 `codex` 不会自动加入共享运行时。

## Web 性能与模块边界

`App.tsx` 负责页面组合、选中会话和用户操作；`transport/host-connection.ts` 按需加载，负责连接、检查点回放、基线补读和实时事件消费。切换 Host 先同步失效旧连接代次，模块加载完成后再次核对代次；授权、未知回执和迟到响应沿用原有保护。主会话与侧边会话共用 `features/use-history.ts`，保证同批事件在 React 渲染前读到最新历史值，连接与草稿生命周期仍由各页面管理。

历史区跟随最新时不测量旧消息行，离开底部后保留真实 DOM 锚点；折叠工具组首次展开才挂载内容，之后保留内部状态。Markdown 按文本复用解析树，文件回调和图片授权通过上下文更新。连续圆角只清理被移除的子树，几何缓存最多 256 项。当前仍保留已加载的历史 DOM，不等同于完整虚拟列表。

国际化使用静态双语词典、单次 `{{name}}` 替换与 `Intl.PluralRules`；变量保持原文，由 React/DOM 转义。词典检查拒绝未实现的格式语法，覆盖复数、语言切换和动态错误。新增语言或复杂格式时先扩展契约及检查。

## 项目、附件与同步

Web 工作模式导航（源码）：Codex↔AgentChat 会切换页面组件。未发送的 Codex 草稿按已认证账户和浏览器设备保留在当前页内存中，草稿键继续区分 Host、原生会话和新建项目；不为此写入 localStorage/IndexedDB，不恢复或重发任务。刷新或关闭页面结束该缓存生命周期，身份变更沿用原有清理逻辑。AgentChat 继续使用下述本地持久存储规则。

项目名称及顺序只取自原生 `project/list`；会话跟随原生目录。完整同步隐藏失效索引，不删除历史或撤销授权；归档会话可跨项目读取，已删除会话不显示。项目自动登记使用官方 `project/create`，主动移除的项目不自动恢复。

附件统一存于 Host 附件库，按 SHA-256 去重并保留会话授权引用；历史附件沿用原路径。图片按授权分块读取并核对哈希和资源变化，外部 HTTP(S) 图片不自动请求。不得开放整个状态目录。

桌面外部变化同步：managed 模式监听 Codex 初始化接口返回目录的系统文件通知，仅把路径当作失效提示，不读取私有数据库或解析会话文件；通过官方接口重新核对会话身份、项目授权和索引，再发送可重放的 `session.contentChanged`。Web 合并短时重复通知，只补读当前可见会话最近一页，保留更早历史、草稿、工具展开和阅读位置；并发流式内容优先，页面返回前台后补读。附着模式继续使用原生通知，原有 15 秒索引核对周期不变，时间戳前进时也提示补读，以恢复遗漏通知。

## AgentChat

对话、接口配置及草稿保存在当前账户的浏览器 IndexedDB，不跨设备同步；云端 `chat_keys` 保存账户归属和加密密钥，不保存聊天。浏览器直接请求供应商 `/models` 与 `/chat/completions`，不携带本站 Cookie、CSRF 或 Referer，不跟随重定向；供应商须允许 CORS。清除浏览器数据会丢失本地历史，关闭页面不能继续生成。

每页最多同时生成 2 条，单条输入上限 12,000 字节、输出 512 KiB、生成 5 分钟。停止会关闭直连请求，断流或刷新不自动重发，未知发送结果须明确确认。当前为纯文字兼容接口，不支持附件、工具或原生 Claude/Gemini 协议。参考 NextChat 的来源与 MIT 许可证保留在 `third_party/nextchat/`。

## Web 语音输入（源码新增）

Web 调用浏览器的 SpeechRecognition / webkitSpeechRecognition，用户点击后才请求录入，不通过 AgentDeck 的 Host、云端或模型转写。浏览器供应商可能联网处理音频；AgentDeck 不上传、保存录音，也不创建音频附件。确认的识别文字只进入当前输入草稿，临时预览独立显示，用户手动发送后沿用既有会话、授权及未知结果核对流程，不执行斜杠命令。每页仅允许一个录入实例，隐藏、切换、卸载或编辑使旧回调失效，避免跨会话写入。

## 工作区工具栏与项目终端（源码新增）

Web 的主对话与侧边对话共用认证后的 Host 连接和快照，分别保存所选会话、历史、流式条目及输入草稿。历史读取共用有界分块及哈希校验；任务、审批和追问继续通过原有固定协议，保留原生身份和未知结果核对。

当前会话更多菜单使用既有 `sessions.rename/pin/fork/archive/restore` 操作及能力检查。未知回执、任务运行或断线阻止修改，分叉/归档保留确认；复制仅写当前浏览器剪贴板，不生成公开分享。右侧打开当前会话绑定原生会话身份，保留主对话和已有标签；新建侧边对话不复制历史。

工具工作区以账户和 Host 为边界保存本页的标签实例；文件工具绑定项目，侧边对话的新建草稿按标签隔离，已存在会话继续使用原生身份。切换标签或收起侧栏只改变可见性，保留实例和终端连接；关闭终端标签会卸载实例并关闭对应 PTY。断线和切换账户/Host 仍清理终端，不自动恢复命令。新标签工具选择页只提供实际已实现的四类工具。

项目终端直接连接当前 Host，打开时在标签绑定的已授权项目根目录启动交互 shell，无需填写 SSH 主机、账号或密钥。Windows 优先使用标准安装位置的 PowerShell 7，未安装则使用系统 Windows PowerShell；Linux/macOS 使用 Host 的绝对路径 `$SHELL`，缺省为 `/bin/sh`。shell 加载自身用户配置。新增 `projectTerminal` 能力及 `terminal.open/read/write/resize/close` 固定操作；open 只接收项目 ID 与终端尺寸，由 Host 校验项目授权、规范路径和目录身份后设置 cwd，不接收客户端程序、命令行或目录。标签固定打开时的项目，主会话切换不迁移终端。

这是用户手动操作、以 Host 系统用户权限运行的终端；项目根目录是启动位置，不是 shell 文件访问沙箱。Codex 的项目授权、沙箱和执行审批维持原流程，不把终端输入转成 Codex 任务。旧 `sshTerminal` / `ssh.*` 继续兼容原客户端，沿用既有 OpenSSH 限制；新 Web 不再提供 SSH 配置表单，也不会将项目终端回退成 SSH。旧 Host 显示升级提示。

终端按已认证 WebSocket 连接和设备归属隔离，最多每连接 2 个、Host 合计 4 个；输出仅在 Host 内存中有界保存 512 KiB，以字节游标分块读取，落后游标明确报告截断。输入按序号确认并在内存中防止重复接收，不进入通用持久操作回执；输入、密码及输出不写入聊天、事件库或诊断。关闭网页连接会关闭对应 PTY，包括尚未完成创建的请求；设备撤销和 Host 停止同样清理，终端不会在恢复时自动重连或重放输入。活跃终端参与 Host 空闲更新检查。云端仍只转发加密连接，无新增数据库迁移；旧客户端忽略新增能力，旧 Host 不提供终端入口。

## 必须保留的边界

操作回执恢复（源码修复）：读请求超时不直接关闭整个通道，独立 hello 探测失败才触发重连；历史及修改操作等待上限为 90 秒，普通读取 30 秒，存活探测 5 秒。修改操作超时后保留原回执，明确的迟到响应按原请求身份结算，不自动重发。Host 保存成功和明确拒绝的完整响应；上游超时/不可用/协议错误、数据库和 I/O 失败按结果未知处理，防重记录保持。Web 沿用现有 `requests.status`，无新 RPC 或数据库迁移；旧 Host 的未知回执仍受保护。只有用户显式核实实际结果后，网页在相同 Web Lock 内重新查询，确认回执未变化、非 pending、Host 快照可读，才释放已核实的浏览器回执；Host 防重记录不删除。查询失败、损坏存储、身份变化和仍在处理均不能人工解除，其他标签页的在途修改不能被确认操作越过。

- 服务端附着的 Codex 是权威源，保留原 `thread/turn/item` 身份；发送 ACK 不代表完成，结果未知先核对，不自动重发。
- 不复制或写入 Codex 私有数据库，不暴露任意 RPC，不因远程访问放宽项目授权或执行确认；凭据不进入文档、日志或测试产物。
- Web 使用 Origin 白名单、HttpOnly Cookie、CSRF 和一次性隧道票据；内层 TLS 校验电脑证书。证书错误不自动回退；浏览器阻止 LAN 时走公网。当前账号 LAN 也依赖云端复核，不承诺云端离线可用。
- 不随意修改协议序列化身份或 Rust 公开入口；旧配对协议仅兼容旧记录和客户端。
- 上游 schema 是生成物，升级 Codex 时显式重导出和核验，不手改；仓库保留独立消息定义，导出与审计统一排除重复聚合包，保留逐文件哈希校验。设置等 Rust 兼容接口保留。
- 附着成功不等于日常原版桌面已经切换；桌面当前运行状态与未完成验收见[运行时验收](runtime.md)与[功能状态](status.md)。
- 不自动修改防火墙，不绕过设备安装确认。
