# 会话管理、模型选择与 chat

## Codex 编程模式

电脑端保持“同步工作区 → 扫码配对”的简单入口。平板按已授权项目组织 AgentDeck 创建的编程会话，支持标题搜索、置顶、重命名、归档、恢复及永久删除；会话行和对话标题旁的 **···** 打开菜单。

两个模式的侧栏仅显示未归档会话。已归档会话统一从 **设置 → 会话管理 → 查看已归档会话** 打开，可搜索、查看内容或恢复；恢复需要二次确认。chat 和 Codex 均使用完整设置页面，顶部“返回对话”或系统返回键返回对话，窄屏使用侧栏抽屉。chat 设置包含共用外观、API 配置及归档管理，保存 API 配置后停留在设置页面。

归档可恢复，删除需要二次确认。删除通过官方 `thread/delete` 永久删除对应 Codex 线程及上游派生子线程，然后移除 AgentDeck 的消息、轮次和审批记录；不会删除工作区文件。当前不导入、展示或建立其他客户端创建的派生线程索引，因此删除提示明确告知上游作用范围。运行中、待审批或状态未知的会话禁止管理操作，需先停止或等待状态核实。置顶仅是 AgentDeck 的本地排序偏好。

输入框上方提供模型和思考强度。模型列表来自当前登录账户的官方 `model/list`，只显示该模型返回的思考强度，发送前 Bridge 再次校验。选择写入真实 `turn/start` 的 `model` / `effort`，并保存为该会话下次发送的偏好。未选择模型时使用 Codex 默认；刷新失败不填充示例模型。更换模型不会改写旧消息。

审批仍逐次由人决定，Diff 仍是当前 Git working tree 的只读视图，可能包含外部改动。模型选择不会扩大项目授权或自动批准工具操作。

## 平板独立 API 模式

无需配对：点顶部 **chat → 配置 API**，填写：

1. **HTTPS 基础地址**，例如 `https://api.openai.com/v1`。不要填完整 `/chat/completions` 路径，不能包含 URL 账号密码、查询串或片段。
2. 该服务商签发的 API 密钥。已有密钥不会回填到输入框；同地址留空可保留，更换地址必须重新输入，避免把旧密钥发给另一主机。
3. 模型 ID 可以留空。点击 **保存并获取模型** 时自动读取对端 `/models`，去重后加入模型菜单并加密保存；未填写模型 ID 时自动选择列表中的第一个。已有选择会保留。不提供此接口的服务商可以手动填写模型 ID，获取失败仍可保存手动配置。模型菜单中的 **获取并添加对端模型** 可刷新列表。

保存后即可发送，重启应用后保留模型列表和选择。使用 OpenAI 兼容 **Chat Completions**：`POST {base}/chat/completions`、Bearer 认证、文本历史、SSE 流式回复；也接受有明确终态的普通 JSON 回复。默认不发送思考强度，显式选择时使用 `reasoning_effort`。模型列表接口不声明这一参数的能力，因此 API 模式的思考强度能否使用取决于服务商和模型，不支持时保留失败状态，不静默改参数。

两种模式的数据隔离：API 消息直接从平板发给所配置服务商，不经过 Windows，也不使用 Codex 登录信息。它是文本对话，不具有项目文件、工具执行、Codex 审批或 Git 能力。连接仍执行正常 TLS 验证，禁止明文 HTTP 和重定向，没有“忽略证书”选项。

chat 会话支持新建、继续、停止、搜索、置顶、重命名、归档/恢复、删除及复制。删除仅移除平板记录，不承诺删除服务商留存。回复只有收到明确 `stop` 完成原因（流式还需 `[DONE]`）才标为完成；提前断流、长度限制、内容过滤、工具调用或不兼容格式显示失败，并保留已收到的部分。用户停止显示中断；应用意外重启时此前运行中的回复变为未知。

API 密钥和会话整体用 Keystore AES-GCM 加密，原子写入应用私有文件；系统备份关闭。仅支持一个 API 配置。最多 100 个会话、每会话约 500 条消息、单次输入 64,000 字符、回复显示 512 Ki 字符、加密前文档 3 MiB。达到上限需删除旧记录。部分流式文本直到结束/停止后才保存，进程意外结束可能失去尚未保存的片段。

## 当前能力边界

| 功能                                                   | Codex 编程模式               | 平板 API 模式                                         |
| ------------------------------------------------------ | ---------------------------- | ----------------------------------------------------- |
| 项目切换                                               | Windows 本机授权目录         | 不访问本机目录                                        |
| 新建、继续、停止                                       | 官方线程/轮次协议            | 文本 API 请求                                         |
| 搜索、置顶、重命名、归档/恢复、删除                    | 已实现，管理操作要求会话空闲 | 已实现，请求期间禁止管理                              |
| 模型、思考强度                                         | 真实账户目录及支持选项       | 自动获取并保存 `/models` 或手动填写，参数依服务商支持 |
| 人工审批、执行事件、真实 Git Diff                      | 已实现                       | 不适用                                                |
| 其他客户端全部历史、活动任务接管                       | 未实现                       | 不适用                                                |
| 会话分叉、编辑后重试、附件、语音、Web 搜索、Git 写操作 | 未实现                       | 未实现                                                |

这是明确范围的功能扩展，不能称为官方 Codex 桌面端的全部功能复制。跨客户端修改标题、归档或删除的自动同步未实现；请在 AgentDeck 管理它创建的线程。当前 Windows Bridge 和 APK 应配套更新，旧 Bridge 不提供新增请求。

## 验证与补测

实现使用固定的 CLI 0.159.2 稳定 schema。Rust fixture 覆盖模型/强度校验、参数真实转发、管理失败不改本地状态、重启持久化、运行中禁止删除、重复请求和删除后的 replay gap。真实隔离 Codex smoke 验证模型目录、指定模型/强度的两次权威完成及恢复、重命名、归档、恢复、删除；不碰用户已有会话。

Android JVM 测试通过带正常主机名验证的本地 HTTPS 测试服务器检查请求、流式结束、提前断流、错误脱敏、拒绝重定向、模型列表、停止和持久化。新增仪器测试检查未配对 API 入口、管理确认和 Keystore 密文；编译测试 APK 不等于执行真机测试。最新实际结果见 [验收记录](ACCEPTANCE.md)。真实服务商 API 测试需在平板配置密钥后执行，不应将密钥粘贴到聊天或日志。
