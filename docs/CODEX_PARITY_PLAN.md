# Codex 完整安卓客户端迁移计划

确认日期：2026-10-21。来源：用户在本聊天确认的计划及实施指令。

## 产品契约

- 目标：完整迁移用户当前安装版 Codex 桌面端全部能力（含实验功能）和内容；电脑执行、存储、提供集成，安卓原生客户端操作。
- 双端共享相同项目、会话、活动任务和服务端配置；不是新建平行聊天系统。
- 平板高度还原布局、内容和交互，手机等价适配，不删功能。不采用远程桌面兜底。
- 浏览器、终端、编辑器、Git、Skills、插件、MCP、hooks、自动化、账户、语音、多媒体均纳入最终目标。
- 局域网直连及私有网络异地访问；公网裸露端口不是默认方案。
- 独立 API 聊天保留为附加入口，与 Codex 权威数据隔离。
- 完成标准：桌面基准中每个入口、内容类型和操作流程都有安卓对应实现及验证证据。仍有阻塞时只能称阶段版。

## 架构约束

Codex 原生会话、任务与配置以其真实权威服务为准；Bridge 只保存访问元数据、索引及必要缓存，安卓 Room 是缓存。禁止复制或直接改写桌面私有数据库维持同步。独立 App Server 读取相同目录不能证明共享活动任务。

公开接口优先，桌面专属能力采用版本化本机适配，文件/Git/终端由受控电脑服务提供。无法可靠接入的功能记录阻塞，禁止用假实现替代。账户令牌不下发安卓。

协议增量提供能力协商、版本兼容、稳定操作标识、冲突检测、分页完整内容、资源传输与分领域事件。截断日志只作预览，完整内容按需读取。双端操作与断线恢复不得重复执行；任务完成依据上游终态，多设备审批只生效一次。

移除强制关闭能力的策略前先核验用户配置与授权映射；不无条件启用 MCP、网络、hooks 或扩大文件权限。客户端设备偏好独立，服务端业务配置共享。

## 阶段与验收门槛

| 阶段 | 交付 | 完成条件 |
| --- | --- | --- |
| 0 基准与可行性 | 安装版版本、账户可用能力、实验开关；页面/菜单/右键/快捷键/消息类型/流程清单；逐项接入路径 | 每项有实现路径或明确阻塞；共享活动任务和多客户端能力有实际证据 |
| 1 共享底座 | 既有项目/全部历史/归档/派生关系；外部变更订阅；活动任务共享；版本、资源、恢复及迁移 | 桌面会话能由安卓继续并双向更新，不生成副本；保留旧配对与映射 |
| 2 完整会话与界面 | 侧栏/顶部/输入框/菜单/设置；分叉、编辑重发、重试、追加、排队；模式权限；完整消息/引用/产物 | 桌面基准全部会话流程可独立完成，平板截图及交互对照通过 |
| 3 工作台 | 文件浏览/搜索/编辑/传输；Diff/评论/审查；Git/分支/工作树/提交/PR；持续终端与浏览器 | 消息到文件到审查贯通，真实调试与交付流程可完成；处理外部修改和冲突 |
| 4 扩展能力 | Skills/插件/MCP/hooks/搜索；电脑调度自动化；账户/额度/分层配置/实验；语音媒体；异地与后台通知 | 每项有真实实现及证据，安卓离线不影响电脑任务和自动化 |
| 5 全量发布 | 关闭差异清单、兼容矩阵、文档、升级备份与回退 | 全量矩阵通过；任何阻塞未解决不得声称完整迁移完成 |

顺序：共享运行时与数据 → 完整会话 → 工作台工具 → 扩展能力 → 全量一致性。桌面升级采用增量基准，不静默改变交付目标。现有 CLI 0.159.2 不限制最终范围，但更换须核验兼容性。

## 验证要求

- 双端新建、继续、分叉、重命名、归档、删除，核对同一身份、内容和派生关系。
- 并发发送/停止/审批/改配置，重复操作、未知结果、断网、服务重启、安卓进程退出及 replay 缺口恢复。
- 长历史、大输出、图片/文件/代码/表格/媒体；预览截断必须可读取完整来源。
- 文件、终端、Git、浏览器、集成、自动化、语音均验证真实结果，fixture 不替代真实验收。
- 平板横竖屏、手机、软键盘、外接键盘；截图与流程分别比较。
- 局域网/异地、撤销、后台通知、旧数据与配对升级、回退。
- 最终端到端：桌面开始任务 → 安卓读完整上下文、补指令、处理交互、编辑与审查 → 桌面继续同一任务，内容和状态一致。
