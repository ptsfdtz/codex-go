## 最新范围与本轮规划

用户最新要求为可收发消息和图片、同步历史、呈现真实 Codex 对话/工具内容及任务状态的安卓客户端；自有服务器只转发加密流量。完整桌面工作台/扩展管理和独立 API 路线退出当前主线。代码取舍、网络方案、连续实施顺序与验收维护在 [PLAN](CODEX_PARITY_PLAN.md)。

后续新增要求：部署网页后，手机/平板/电脑浏览器打开网址即可使用，不要求安装 App/VPN，安卓仍保留。已核对当前接口拒绝 Origin、依赖 Authorization 头与自签名固定证书，Tauri 前端仅为管理页，设备替换会撤销旧设备；浏览器入口不能直接复用。PLAN 已补 Web/PWA、浏览器会话/允许源、公开信任证书、多设备及反向 TCP 隧道方案，尚未实现或部署。

本轮已核对 Android/Rust 对话、附件、图片、网络、权限和功能入口依赖，并查看 [官方移动端网页交互演示和远程文档](../baselines/codex-mobile-2026-10-22.md)。发现：附件总量 512 KiB，图片主要为按钮打开及受限本地来源，Markdown 尚无完整图片/公式/高亮配置；自有中继未实现，原版桌面完整共享仍未完成。考虑新增网页免安装要求，推荐成熟反向 TCP 隧道，VPN 仅作可选验证路径，不并行自研两套。

本轮只调整规划与接手文档，未删除/停用产品代码、修改数据或凭据、部署中转、执行编译/业务测试/真机验证、提交或推送。官方网页演示使用模拟数据，不是本项目真实源或原生手机验收。原全桌面计划已归档，范围调整不提升旧阶段状态。
