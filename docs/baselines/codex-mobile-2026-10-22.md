# 官方 Codex 移动端参考

观察日期：2026-10-22。用于安卓对话客户端的产品规划，不是本项目实现或原生手机验收。

## 来源与观察方法

- [Codex on mobile](https://learn.chatgpt.com/docs/mobile)：从 developers.openai.com/codex/mobile 跳转到此页，实际打开并操作页面内交互式 iPhone 演示。
- [Remote connections](https://learn.chatgpt.com/docs/remote-connections)：通过该站 WebMCP lookup_page 读取完整正文。

官方演示自身明确采用 simulated data；本次查看了网页截图和可访问性树，没有登录或实测原生手机应用。文档的可用性受平台、版本、账户和 rollout 影响。界面演示、文档说明与本项目真实接口能力分别记录。

## 已观察界面与行为

| 场景 | 网页实际呈现 | 本项目应学习的设计 |
| --- | --- | --- |
| 任务列表 | All/Cloud/电脑筛选，电脑 Online，Pinned/Today 分组，运行/未读提示，搜索和新任务输入框 | 以电脑与对话为中心，清晰区分在线、未读和运行状态；本项目没有 Cloud 时不添加空的云端入口 |
| 会话 | 顶部标题和项目/电脑，返回/菜单；用户气泡、助手正文、Thinking、复制等操作、底部输入框 | 消息为主体，任务和电脑身份可见，回复过程与结果连贯 |
| 活动展开 | Worked 摘要可展开；搜索、读取、编辑分项均有 Complete 和折叠入口 | 将工具活动分组，保留具体输出与状态，不把协议事件逐条显示成聊天气泡 |
| 审批 | 命令正文，Permission requested，Approve、Approve for this session、Deny 和补充说明入口 | 审批靠近对话并呈现实际命令；现协议只支持一次审批，不能为模仿外观新增无后端授权语义的整会话批准 |
| 结果审查 | 会话中显示 changed files/增删统计；点击打开带文件与代码块的 Diff 面板 | 保留任务内只读文件/Diff 阅读，不因此要求完整 Git 写入或桌面工作台 |
| 新建任务 | 选择 Host/Environment，任务输入、附件、权限、模型文字和语音图标 | 新任务需明确运行电脑/项目，输入框整合会话必要设置；模型名不硬编码复制演示值 |

附件图标在本次网页演示点击后没有打开选择界面，不能证明图片上传行为。演示未验证真实图像消息、公式、音视频、交互产物、流式性能或端到端传输；这些仍需按用户要求和真实 Codex 消息对照实现。

## 文档明确的能力

远程连接文档列出：新建/继续会话、补充指令、回答问题、引导活动任务、审批操作、查看输出/Diff/测试结果/终端输出/截图、完成或需要关注时通知、电脑与会话切换。执行环境、文件、工具、凭据和权限来自连接的电脑；电脑不可达时，普通远程连接停止。

正文提到 secure relay layer 帮助可信设备连通，但没有在本次资料中提供将官方客户端中继地址改成自有服务器的公开部署合约。因此规划是复用现有 Android/Bridge 构建自己的客户端与连接路径，而非修改官方应用地址。Work Cloud 的云端继续执行属于另外的能力，本项目纯转发 VPS 不包含云端执行或会话存储。

## 与现有实现的映射

- 保留会话、composer、history、messages、approvals；原生问题回答、计划、工具结果及通知都属于移动对话体验。
- 复用 review 的显示组件，但当前 working-tree Diff 不代表历史任务 Diff，需建立来源关联。
- 收敛完整桌面管理页与独立 API 入口；项目归属、权限、技能引用和图片资源读取基础保留。
- 图片内联显示、较大附件、公式、高亮及富媒体按真实输出补齐，不能用官方网页模拟演示替代项目验收。
